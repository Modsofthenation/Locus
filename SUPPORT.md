# Support

- **Bugs and features** — [GitHub Issues](https://github.com/Modsofthenation/Locus/issues). Use the bug or feature template.
- **Security** — guest escapes, token leaks, and unauthenticated control-plane access go through [private vulnerability reporting](https://github.com/Modsofthenation/Locus/security/advisories/new). See [SECURITY.md](SECURITY.md).
- **How it is put together** — [docs/architecture.md](docs/architecture.md) and [CONTRIBUTING.md](CONTRIBUTING.md).

This is not a hosted service. There is no operator dashboard or support mailbox beyond the repository.
